\chapter{Messages}
This appendix lists, in alphabetical order, the messages that InitechDOS
displays.  Each message is shown exactly as it appears on the screen.  Where
a message names a drive, \ph{d} stands for the drive letter.  The number
beside each message identifies it when you call the Help Desk (extension
2504).  Appendix~A of the \doctitle{InitechDOS Reference} explains each
message and the action to take, and lists the messages that individual
commands display.

When InitechDOS cannot read or write a disk, it asks
\texttt{Abort, Retry, Fail?}  Press \type{R} to try again after correcting
the problem (for example, closing the drive door), \type{A} to end the
program, or \type{F} to let the program continue.
