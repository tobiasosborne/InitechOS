\begin{XbaseEntry}{CONSOLE}{set}
Turns the display of output on the screen on or off.
\Syntax
\SyntaxLine{\kw{SET CONSOLE} \kw{ON}/\kw{OFF}}
\Defaults
ON.
\Usage
With SET CONSOLE OFF, the output of the commands of a program is not
displayed, and what is typed in answer to its prompts is not echoed.
Commands typed at the dot prompt and error messages are displayed whatever
the setting.  Output that SET ALTERNATE copies to a file is written to the
file in either case.
\SeeAlso{SET TALK, REPORT FORM}
\end{XbaseEntry}
