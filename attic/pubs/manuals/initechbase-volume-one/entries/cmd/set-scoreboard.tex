\begin{XbaseEntry}{SCOREBOARD}{set}
Controls the reserved top line of the command screen.
\Syntax
\SyntaxLine{\kw{SET SCOREBOARD} \kw{ON}/\kw{OFF}}
\Defaults
ON.
\Usage
With SCOREBOARD ON, command output scrolls below the top line.
With SCOREBOARD OFF, output may use that line too.
Changing the setting clears the command page before the next dot prompt.
\SeeAlso{CLEAR, SET STATUS}
\end{XbaseEntry}
