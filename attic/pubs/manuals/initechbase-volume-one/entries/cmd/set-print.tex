\begin{XbaseEntry}{PRINT}{set}
Sends console output to the printer as well as the screen.
\Syntax
\SyntaxLine{\kw{SET PRINT} \kw{ON}/\kw{OFF}}
\Defaults
OFF.
\Usage
With SET PRINT ON, what \cmd{?} and \cmd{??} display is also sent to the
printer, with the left margin set by SET MARGIN.  This version has been checked
against the original product only for that margin behaviour; other effects of
SET PRINT, including PROW() and PCOL() and the response to a bad setting, are
not yet checked.
\SeeAlso{SET DEVICE, EJECT, PCOL()}
\end{XbaseEntry}
