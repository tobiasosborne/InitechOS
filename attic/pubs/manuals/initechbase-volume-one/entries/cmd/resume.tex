\begin{XbaseEntry}{RESUME}{command}
Continues a suspended program.
\Syntax
\SyntaxLine{\kw{RESUME}}
\Usage
When \key{Esc} interrupts a program and you answer \key{S} (Suspend),
InitechBase displays \texttt{Do suspended} and the dot prompt, with the
program, its memory variables and its databases left as they were.  Any
command may then be typed.  \cmd{RESUME} continues the program at the line
where it was interrupted; \cmd{CANCEL} ends it instead.

With no program suspended, \cmd{RESUME} displays \xmsg{101}{Not suspended.}
\SeeAlso{CANCEL, SET ESCAPE}
\end{XbaseEntry}
