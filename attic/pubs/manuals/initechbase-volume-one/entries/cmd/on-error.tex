\begin{XbaseEntry}{ON ERROR}{compound}
\XAlso{ON}{ON}%
Names a command to be carried out when an error occurs.
\Syntax
\SyntaxLine{\kw{ON ERROR} \opt{\xp{command}}}
\Usage
After \cmd{ON ERROR} \xp{command}, whenever a command cannot be carried out,
InitechBase carries out \xp{command} in place of the error message.  In a
program, the program then goes on with the command that follows the one that
failed.  The function \fn{ERROR()} gives the number of the error while the
command runs and afterwards, so the command can record or report it.  The
command is often \cmd{DO} of a procedure that handles errors.

\cmd{ON ERROR} with no command removes the trap.  A new \cmd{ON ERROR} replaces
the one before.

\end{XbaseEntry}
