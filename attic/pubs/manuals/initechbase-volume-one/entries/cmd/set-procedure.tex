\begin{XbaseEntry}{PROCEDURE}{set}
Opens a procedure file whose procedures \cmd{DO} can run by name.
\Syntax
\SyntaxLine{\kw{SET PROCEDURE TO} \opt{\xp{procedure file}}}
\Defaults
No procedure file open.
\Usage
A procedure file is a program file of \cmd{PROCEDURE} parts.  While one is
open, \cmd{DO} \xp{name} can call a procedure of that name in the procedure
file.  It takes precedence over the program file \xp{name}\texttt{.PRG}
on the disk.
You need not type the extension.  Only one procedure file can be open at a
time: opening another closes the first, and \cmd{SET PROCEDURE TO} with no
file name closes it.  A procedure file that is not on the disk is refused
with \xmsg{1}{File does not exist.}

\cmd{CLOSE PROCEDURE} and \cmd{CLOSE ALL}, when executed outside an active
library procedure, close the procedure file; a later \cmd{DO} of the same
name runs the disk program.  When either close command is executed inside
an active library procedure, that procedure finishes and the library
remains selected for later calls, even after it returns.
\SeeAlso{DO, PROCEDURE, RETURN}
\end{XbaseEntry}
