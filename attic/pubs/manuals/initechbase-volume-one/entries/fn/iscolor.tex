\begin{XbaseEntry}{ISCOLOR}{function}
Returns a logical value that is true when the system is running in color.
\Syntax
\SyntaxLine{\kw{ISCOLOR()}}
\Usage
The result is .T. on a color display and .F. on a monochrome display.
Choosing white on black with SET COLOR TO W/N does not change the display's
color capability. The function takes no argument; an argument raises
\xmsg{11}{Invalid function argument.}.
\Examples
On a color display:
\begin{TypeIn}
. ? "svga", ISCOLOR(), TYPE("ISCOLOR()")
svga .T. L
\end{TypeIn}
\SeeAlso{SET COLOR, TYPE()}
\end{XbaseEntry}
