\begin{XbaseEntry}{MESSAGE}{function}
Returns the text of the error handled by an ON ERROR command, as a character string.
\Syntax
\SyntaxLine{\kw{MESSAGE()}}
\Usage
\fn{MESSAGE()} takes no argument; a call with any argument raises \xmsg{11}{Invalid function argument.}. The text is that of the message whose number \fn{ERROR()} returns, without the number. It remains after the ON ERROR command, like the number. Before any error has been handled the result is an empty string.
\Examples
\DotExample{examples/fn-message}
\SeeAlso{ERROR(), ON ERROR}
\end{XbaseEntry}
