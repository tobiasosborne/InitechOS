\CardBand{InitechWord Installation and Start-Up}
\begin{CardText}
InitechWord comes installed: the program is the file \textbf{WORD.EXE} in
the \textbf{APPS} folder of the InitechOS data volume.  There is nothing to
copy.  To start InitechWord the first time,
\begin{CardSteps}
\item Start InitechOS and wait until the FLAIR desktop is on the screen.
\item Double-click the icon of the data volume.  Its window opens.
\item Double-click the \textbf{APPS} folder.
\item Double-click \textbf{WORD.EXE}.  The InitechWord window opens, with
the status line \texttt{Doc 1 Pg 1 Ln 1" Pos 1"} at the bottom.
\end{CardSteps}
\end{CardText}
\CardFoot{\hfill{\itshape (See other side)}\hfill}
\end{CardPanel}
\begin{CardPanel}
\begin{CardText}
\begin{CardSteps}[start=5]
\item Lay the function-key template above the function keys of your
keyboard.
\item Type a line of text.  Press Enter only at the end of a paragraph.
\item Press \textbf{Save} (\K{F10}).  At \texttt{Document to be Saved:} type
a name of up to eight letters, for example \textbf{test}, and press Enter.
The name appears at the left of the status line.
\end{CardSteps}
\end{CardText}
\end{CardPanel}
\begin{CardPanel}
\begin{CardText}
\begin{CardSteps}[start=8]
\item Press \textbf{Exit} (\K{F7}).  At \texttt{Save Document? Yes (No)} type
\textbf{n}: the document is already saved.
\item At \texttt{Exit WP? No (Yes)} type \textbf{y}.  The InitechWord window
closes.
\end{CardSteps}
InitechWord is ready for use.  The document you saved is on the data volume;
retrieve it with \textbf{Retrieve} (\K{Shift-F10}).  Begin with
\textit{Getting Started} in the \textit{InitechWord Reference}, then the
lessons of the \textit{InitechWord Workbook}.
\end{CardText}
\end{CardPanel}
