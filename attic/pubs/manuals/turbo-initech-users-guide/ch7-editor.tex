\chapter{The editor}
\ix{editor}

\draft{the Turbo Initech editor is part of the integrated environment of
milestone M8 (ADR-0007 DEC-08, bead initech-ls4); its keys are not designed
(ADR-0007 OQ-3)}
The editor of the integrated environment will edit one Pascal source file
at a time and save it through InitechDOS.  This chapter will list its keys
and commands, grouped as cursor movement, insertion and deletion, blocks,
search and replace, and file commands, when they are designed.

Meanwhile, any editor that writes plain text files serves: the InitechDOS
line editor EDLIN is described in the \doctitle{InitechDOS Reference}.
Turbo Initech accepts lines ended by a line feed or by a carriage return
and a line feed, and ignores tab characters as blanks.
