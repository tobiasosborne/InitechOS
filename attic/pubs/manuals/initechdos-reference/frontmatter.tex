\FrontChapter{About This Book}
This book is the reference for the commands of InitechDOS Version~3.30.  It
describes each command, the commands you put in the configuration file
\file{CONFIG.SYS}, the commands used in batch files, and the messages
InitechDOS displays.  Keep it beside your computer and consult it when you
need the exact form of a command or the meaning of a message.

\section{Read This First}
If you have not used InitechDOS before, begin with the \doctitle{InitechDOS
\Slip{VO30-01}{Users Guide}}.  It shows you how to start the system, how to type commands,
and how to look after your files, in short exercises that you carry out at
the keyboard.  Come back to this book when you need the details of a
command.

\section{First-Time Users}
Read Chapter~1, ``How to Use This Book,'' and the first part of Chapter~2,
``InitechDOS Commands,'' which explains the notation used in the command
entries and the information that applies to every command.  Then look up
the commands as you need them.

\section{Experienced Users}
If you have used a disk operating system before, read the notation section
at the beginning of Chapter~2, then turn directly to the commands.  The
entries state exactly what InitechDOS Version~3.30 does, including the
places where it differs from what you may be used to.

\section{Terms Used}
\SideHead{Diskette}A flexible disk in a diskette drive.

\SideHead{Fixed disk}A disk that is built into the computer and cannot be
removed.

\SideHead{Disk}Either a diskette or a fixed disk.

\SideHead{Source}The disk, directory or file that information is copied
from.

\SideHead{Target}The disk, directory or file that information is copied
to.

\SideHead{Default}The drive, directory or value InitechDOS uses when you do
not name one.

\section{How This Book Is Organized}
\SideHead{Chapter 1}How to Use This Book describes the parts of a command
entry and the practice diskette used in the examples.

\SideHead{Chapter 2}InitechDOS Commands gives the notation and the
information common to all commands, then one entry for each command, in
alphabetical order.

\SideHead{Chapter 3}Configuring Your System describes the \file{CONFIG.SYS}
file and each command you can put in it.

\SideHead{Chapter 4}Batch Files describes batch files, the file
\file{AUTOEXEC.BAT}, and each batch subcommand.

\SideHead{Appendix A}Messages lists the messages InitechDOS displays, with
an explanation of each and the action to take.

An index and three Reader's Comment Forms are at the back of the book.
