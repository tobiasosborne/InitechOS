This book was typeset by Initech Publications with LuaLaTeX from TeX Live,
using the \texttt{initech-manual} document class.  The text face is TeX
Gyre Termes or TeX Gyre Schola, according to the book; headings, labels and
tables are set in TeX Gyre Heros and TeX Gyre Heros Cn, examples and screens
in TeX Gyre Cursor, and the cover titles in TeX Gyre Termes.  The TeX Gyre
faces are metric-compatible replacements for Times, New Century Schoolbook,
Helvetica and Courier.

Every screen reproduction and example transcript in this book was captured
from InitechOS running under the QEMU emulator, driven by the project's test
harness from a recorded list of keystrokes.  The text of the display was read
back from each screendump character by character by the harness program
\texttt{console\_text}, and the build compares every capture with the running
system again before the book is printed.
