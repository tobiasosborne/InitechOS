The Turbo Initech integrated environment is a full-screen program that
runs on InitechOS and brings the editor, the compiler and the running
program together on one blue screen.  It will let you:

\begin{itemize}
\item edit a program, reading and writing its file through InitechDOS;
\item compile it with the resident Turbo Initech compiler;
\item run the compiled program.
\end{itemize}

The environment will also be where Turbo Initech compiles itself from
inside InitechOS (the \doctitle{Self-Compilation Guide}).  Until it is
available, programs are written with an editor such as EDLIN and compiled
with \file{TPS.COM} as Chapters 1 and 5 describe.  This chapter will
describe each menu and command of the environment when its design is
complete.
