\chapter{Saving and Retrieving}

This chapter saves the sales table, ends Initech 123, and brings the table
back.

\section{What This Chapter Shows You}
\begin{itemize}
\item Saving a worksheet
\item Ending the session
\item Retrieving a worksheet
\end{itemize}

\section{Saving}
\ix{saving}
\begin{Keystrokes}
\Do{Press}{\kname{SLASH}}{type \type{f}, \type{s} (File Save)}
\Do{Type}{\type{REGIONS}}{and press \kname{ENTER}}
\end{Keystrokes}
\FlairShot[fig:qs3]{qs3}{The table saved as REGIONS}

\section{Ending and Starting Again}
Select \slashcmd{/Quit Yes} to end the session; the worksheet is saved, so
Initech 123 ends at once.  Start Initech 123 again, then retrieve the
table:
\begin{Keystrokes}
\Do{Press}{\kname{SLASH}}{type \type{f}, \type{r} (File Retrieve)}
\Do{Type}{\type{REGIONS}}{and press \kname{ENTER}}
\end{Keystrokes}
The table returns with its formats, its column width and the cell pointer
where you left it; the status line names the file
(Figure~\ref{fig:qs3b}).
\FlairShot[fig:qs3b]{qs3b}{REGIONS retrieved}

\section{Saving Again}
\ix{Replace}
Change a number, then save the table under the same name.
\begin{Keystrokes}
\Do{Press}{\fkey{Goto}{F5}}{type \type{b2} and press \kname{ENTER}}
\Do{Type}{\type{1450}}{and press \kname{ENTER}}
\Do{Press}{\kname{SLASH}}{type \type{f}, \type{s}; the prompt offers
  the current file, REGIONS}
\Do{Press}{\kname{ENTER}}{}
\end{Keystrokes}
A file named REGIONS already exists, so Initech 123 asks what to do with
it (Figure~\ref{fig:qs3c}).  Select \textbf{Replace} to write the changed
table over it, or \textbf{Cancel} to keep the file as it is.
\FlairShot[fig:qs3c]{qs3c}{Saving over REGIONS}
