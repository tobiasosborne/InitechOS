\chapter{Saving and Retrieving}

This chapter saves the sales table, ends Initech 123, and brings the table
back.

\section{What This Chapter Shows You}
\begin{itemize}
\item Saving a worksheet
\item Ending the session
\item Retrieving a worksheet
\end{itemize}

\section{Saving}
\ix{saving}
\begin{Keystrokes}
\Do{Press}{\kname{SLASH}}{type \type{f}, \type{s} (File Save)}
\Do{Type}{\type{REGIONS}}{and press \kname{ENTER}}
\end{Keystrokes}
\FlairShot[fig:qs3]{qs3}{The table saved as REGIONS}

\section{Ending and Starting Again}
Select \slashcmd{/Quit Yes} to end the session; the worksheet is saved, so
Initech 123 ends at once.  Start Initech 123 again, then retrieve the
table: press \kname{SLASH}, type \type{f}, \type{r}, type \type{REGIONS} and
press \kname{ENTER}.
