\chapter{Solving Problems}
\newcommand\Problem[1]{\par\addvspace{8pt}\noindent\textbf{Problem:\ #1}\par\nobreak\vspace{2pt}}
\newcommand\Solution{\noindent\textbf{Solution:}\ }

If Initech 123 does not start or end as Chapter~2 describes, look for the problem
here.  Problems that arise while you work are in Appendix~B of the
\doctitle{Initech 123 Reference}.

\Problem{I cannot find 123.EXE.}
\Solution Initech 123 is in the folder \file{APPS} of the InitechOS data
disk.  Open the data disk's window first, then the folder.

\Problem{When I double-click 123.EXE, no window appears, or the window closes
at once.}
\Solution
\begin{itemize}
\item Initech 123 reads its menus from \file{123.MNU} in the \file{APPS}
  folder and does not start without it.  Make sure the file is there; if it
  is, copy it again from your InitechOS diskettes.
\item Check that your computer has a numeric coprocessor (Chapter~1).
\end{itemize}


\Problem{Pressing \key{PgDn}, \key{Tab}, \key{End} or \key{F1} does
nothing.}
\Solution These keys have no function in this version of Initech 123
(Chapter~3).  Move the cell pointer with the arrow keys, or go straight to a
cell with \fkey{Goto}{F5}.

\Problem{When I quit, Initech 123 ends at once without asking whether to
save.}
\Solution The worksheet has no unsaved changes: you have not changed it
since you last saved or retrieved it, and you were not typing an entry.
Initech 123 asks only when there is work to lose.

\Problem{When I quit, Initech 123 asks whether to save, and I do not want
to end the session after all.}
\Solution Select \textbf{Cancel}.  The worksheet, and an entry you were
typing, stay as they were.

\Problem{A worksheet I saved does not appear when I retrieve it by name.}
\Solution Initech 123 looks for the name on drive \file{A:} with the
extension \file{.WK1} unless you type another.  Check the spelling, and
type the extension if you saved the file with one of your own.  Chapter~4
describes file names.
