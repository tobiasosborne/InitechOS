\chapter{Installing InitechBase}
\Gates{test-pubs-screens, test-pubs-samir-disk, test-samir-boot, test-samir-ovl-emu}
This chapter lists what you need to use InitechBase, describes the InitechBase
package, and tells you how to make the working copies of the diskettes that
you use every day.

\ATEHead{What You Need}
InitechBase runs under InitechDOS Version~3.30.  You need:
\begin{itemize}
\item A computer that runs InitechDOS Version~3.30, as described in the
  \doctitle{InitechDOS User's Guide}
\item InitechDOS Version~3.30
\item A diskette drive, or a fixed disk with room for the InitechBase files and
  your databases
\end{itemize}

\begin{itemize}

\ATEHead{Making Working Copies}
Never work with the diskettes of the package.  Copy their files to the disk you
will work on, and keep the diskettes in a safe place.  Copy all the files of
both diskettes into one directory of your fixed disk, or onto one working
diskette, with the InitechDOS command \file{COPY}: put the diskette of the
package in drive~A and the working diskette in drive~B, and type
\type{COPY A:*.* B:} at the InitechDOS prompt.  For a fixed disk, name its
drive and directory instead of \file{B:}.  The \doctitle{InitechDOS User's Guide} describes \file{COPY}, the
creation of directories, and diskettes and fixed disks.

\file{SAMIR.EXE} reads parts of itself from \file{SAMIR.OVL} while it runs, so
keep the two files together and start InitechBase from the directory that
holds them.  If \file{SAMIR.OVL} is not there, or is damaged, or belongs to
another release of \file{SAMIR.EXE}, InitechBase displays
\type{Insert System Disk and press ENTER, or press Ctrl-C to abort.}
Put the right \file{SAMIR.OVL} in place and press Enter to go on, or press
Ctrl-C to return to InitechDOS.
