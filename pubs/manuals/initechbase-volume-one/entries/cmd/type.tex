\begin{XbaseEntry}{TYPE}{command}
Displays the contents of a text file.
\Syntax
\SyntaxLine{\kw{TYPE} \xp{file}}
\Usage
\cmd{TYPE} displays the file named, up to its end-of-file mark
(\key{Ctrl-Z}).  Give the name with its extension; none is assumed.  Use it
for program files, report output written with \kw{TO FILE}, and other text
files.  A database that is open cannot be displayed
(\xmsg{3}{File is already open.}).
\Examples
\DotExample{examples/c-type}

\end{XbaseEntry}
