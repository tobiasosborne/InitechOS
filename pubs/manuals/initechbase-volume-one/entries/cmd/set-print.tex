\begin{XbaseEntry}{PRINT}{set}
Sends console output to the printer as well as the screen.
\Syntax
\SyntaxLine{\kw{SET PRINT} \kw{ON}/\kw{OFF}}
\Defaults
OFF.
\Usage
With SET PRINT ON, what \cmd{?} and \cmd{??} display is also sent to the
printer, with the left margin set by SET MARGIN, and the printer position
\fn{PROW()} and \fn{PCOL()} advances with it.  The screen is unaffected.
Anything other than ON or OFF raises \xmsg{10}{Syntax error.}.
\SeeAlso{SET DEVICE, EJECT, PCOL()}
\end{XbaseEntry}
