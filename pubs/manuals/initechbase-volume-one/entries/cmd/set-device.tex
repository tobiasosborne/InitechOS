\begin{XbaseEntry}{DEVICE}{set}
Chooses the device that receives positioned SAY output.
\Syntax
\SyntaxLine{\kw{SET DEVICE TO} \kw{SCREEN}/\kw{PRINT}}
\Defaults
SCREEN.
\Usage
With SET DEVICE TO SCREEN, \cmd{@} SAY displays its expression at the given
screen position and updates \fn{ROW()} and \fn{COL()}.  With SET DEVICE TO
PRINT, it writes at the given printer position and updates \fn{PROW()} and
\fn{PCOL()}.  Output to one device leaves the position of the other alone.
This version accepts printer rows 0 through 24 and columns 0 through 79;
a position outside those limits raises
\xmsg{30}{Position is off the screen.}.

SET DEVICE does not change the destination of \cmd{?} or \cmd{??}; those
commands continue to advance the screen cursor.

\end{XbaseEntry}
