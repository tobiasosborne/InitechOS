\begin{XbaseEntry}{EJECT}{command}
Advances the printer to the top of the next page.
\Syntax
\SyntaxLine{\kw{EJECT}}
\Usage
\cmd{EJECT} sends a carriage return and a form feed to the printer and sets
the printer position to row 0, column 0.  It works whether or not SET PRINT is
ON.  Anything typed after the word EJECT is ignored.
\SeeAlso{SET DEVICE, PCOL()}
\end{XbaseEntry}
