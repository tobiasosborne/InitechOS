\begin{XbaseEntry}{ALTERNATE}{set}
Copies what InitechBase displays to a text file.
\Syntax
\SyntaxLine{\kw{SET ALTERNATE TO} \opt{\xp{file}}}
\SyntaxLine{\kw{SET ALTERNATE} \kw{ON}/\kw{OFF}}
\Defaults
OFF, and no file.
\Usage
SET ALTERNATE TO creates the text file named, replacing a file of that name;
if no extension is given, \file{.TXT} is assumed.  SET ALTERNATE ON then
copies to the file everything InitechBase displays, until SET ALTERNATE OFF.
The file receives the output even while SET CONSOLE is OFF, so a program can
write a report to a file without showing it.

SET ALTERNATE TO with no file name closes the file; \cmd{QUIT} closes it
too.  Display the file with \cmd{TYPE}.
\SeeAlso{SET CONSOLE, TYPE}
\end{XbaseEntry}
