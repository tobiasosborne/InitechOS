\begin{XbaseEntry}{LUPDATE}{function}
Returns the date of the last update to the database in the selected work area, as a date value.
\Syntax
\SyntaxLine{\kw{LUPDATE()}}
\Usage
\fn{LUPDATE()} takes no argument; a call with any argument raises \xmsg{11}{Invalid function argument.}. With no database in USE, it returns a blank date.
\Examples
\DotExample{examples/fn-lupdate}
\SeeAlso{DBF(), DATE(), USE}
\end{XbaseEntry}
