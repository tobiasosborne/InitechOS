\begin{XbaseEntry}{NDX}{function}
Returns the name of an open index file in the selected work area, as a character string.
\Syntax
\SyntaxLine{\kw{NDX(}\xp{expN}\kw{)}}
\Usage
\fn{NDX()} takes one numeric argument from 1 through 7, selecting an index in
the order it was opened. An unused slot from 1 through 7 returns an empty
string. A slot outside that range gives an empty string while the current
statement finishes, then raises \xmsg{87}{NDX(): Invalid index number.}.
A nonnumeric argument or a call with other than one argument raises
\xmsg{11}{Invalid function argument.}.

\end{XbaseEntry}
