\begin{XbaseEntry}{READKEY}{function}
Returns the number representing the key used to leave a full-screen command.
\Syntax
\SyntaxLine{\kw{READKEY()}}
\Usage
Before a full-screen command has run, the result is 0. Repeated calls leave
the value unchanged. The function takes no argument; an argument raises
\xmsg{11}{Invalid function argument.}.
\Examples
With no full-screen command having run:
\DotExample{examples/fn-readkey}
\SeeAlso{TYPE()}
\end{XbaseEntry}
