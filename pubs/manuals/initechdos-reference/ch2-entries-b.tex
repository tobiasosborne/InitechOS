% EDLIN -- os/milton/edlin.c (edlin_run: name, /B, the .BAK refusal, "New
% file" / "End of input file", the '*' prompt; commands(): line numbers
% n . # +n -n, A C D E I L M P Q R S T W and a bare line number; readline:
% the template keys through AH=07h, Ctrl-C ends insert, Ctrl-V quotes;
% save(): .$$$ then .BAK, Ctrl-Z appended).  Model: MS-DOS 3.3 User's Guide
% pp.162-193 (harness/edlin/README.md).  Shipped as DOS\EDLIN.COM (Makefile
% flair-data-rules).  Gates: test-edlin-host, test-edlin-emu (+ -mutant).
\begin{DosEntry}{EDLIN}{Line Editor}{external}
\Purpose Creates and changes text files, one line at a time.
\Format \SyntaxLine{\kw{EDLIN} \opt{\ph{d}\kw{:}}\opt{\ph{path}}\ph{filename}\opt{\kw{.}\ph{ext}} \opt{\kw{/B}}}
\Type{External}
\Remarks
\Param{filename} names the file to edit.  If the file does not exist,
\cmd{EDLIN} displays \texttt{New file}; otherwise it reads the file into
memory and, when the whole file has been read, displays \texttt{End of
input file}.  A file with the extension \file{.BAK} cannot be edited:
\cmd{EDLIN} displays \texttt{Cannot edit .BAK file--rename file}.

\Param{/B} reads the whole file, including any \key{Ctrl-Z} characters in
it.  Without \kw{/B}, the file ends at the first \key{Ctrl-Z}.

\cmd{EDLIN} prompts with an asterisk (\texttt{*}).  Each command is a
letter, preceded by the line numbers it works on; separate two line
numbers with a comma.  A line number may be a number, a period (\type{.},
the current line), a number sign (\type{\#}, the line after the last), or a
plus or minus sign and a number (lines after or before the current line).
When \cmd{EDLIN} lists lines it shows each line's number, and an asterisk
after the number of the current line.
\par\medskip
\begin{list}{}{\leftmargin=56mm \labelwidth=54mm \labelsep=2mm
  \itemsep=1pt \parsep=0pt \topsep=2pt
  \renewcommand\makelabel[1]{\parbox[t]{54mm}{\RaggedRight #1}}}
\item[{\imSideHeadFont Command}] {\imSideHeadFont Action}
\item[\ph{line}] Displays the line and lets you change it
\item[\opt{\ph{n}}\kw{A}] Reads \ph{n} more lines of a large file
\item[\ph{line},\ph{line},\ph{line}\opt{,\ph{count}}\kw{C}] Copies lines in front of a line
\item[\opt{\ph{line}}\opt{,\ph{line}}\kw{D}] Deletes lines
\item[\kw{E}] Saves the file and ends \cmd{EDLIN}
\item[\opt{\ph{line}}\kw{I}] Inserts lines in front of a line
\item[\opt{\ph{line}}\opt{,\ph{line}}\kw{L}] Lists lines
\item[\ph{line},\ph{line},\ph{line}\kw{M}] Moves lines in front of a line
\item[\opt{\ph{line}}\opt{,\ph{line}}\kw{P}] Lists lines a screen at a time
\item[\kw{Q}] Ends \cmd{EDLIN} without saving
\item[\opt{\ph{line}}\opt{,\ph{line}}\opt{\kw{?}}\kw{R}\ph{old}\key{Ctrl-Z}\ph{new}] Replaces text
\item[\opt{\ph{line}}\opt{,\ph{line}}\opt{\kw{?}}\kw{S}\ph{text}] Searches for text
\item[\opt{\ph{line}}\kw{T}\ph{filename}] Merges another file in front of a line
\item[\opt{\ph{n}}\kw{W}] Writes \ph{n} lines of a large file to disk
\end{list}
\par\medskip
In insert mode (\kw{I}), each line you type is inserted when you press
\key{Enter}; press \key{Ctrl-C} to return to the asterisk prompt.  When you
change a line, \cmd{EDLIN} offers the old line as a template: \key{F3}
copies the rest of it, \key{F1} one character of it, \key{Del} skips one
character, \key{Ins} switches between inserting and overtyping, and
\key{Esc} starts the line again.  Press \key{Enter} at once to keep the line
unchanged.  With \kw{?}, \kw{R} and \kw{S} ask \texttt{O.K.?} at each match.
\kw{S} and \kw{R} remember their text, and match capital and small letters
exactly.

\kw{E} writes the file and keeps the original under the same name with the
extension \file{.BAK}.  \kw{Q} asks \texttt{Abort edit (Y/N)?}; type
\type{Y} to end without changing the file.
\Example
The example deletes line 4 of the telephone list, lists the file, saves it,
and lists the file and its backup:
\Shot{edlin}
\end{DosEntry}

% EXIT -- os/milton/command.c dispatch_line CMD_EXIT (a permanent processor
% ignores EXIT without a message; a secondary returns to its parent).
% Gates: test-shell-permanent, test-exit-handles.
\begin{DosEntry}{EXIT}{}{internal}
\Purpose Ends a secondary command processor and returns to the program that
started it.
\Format \SyntaxLine{\kw{EXIT}}
\Type{Internal}
\Remarks
A program can start a second copy of the command processor so that you can
type commands without leaving the program.  \cmd{EXIT} ends that copy and
returns you to the program.

The command processor that InitechDOS starts when the system is turned on
is permanent.  At its prompt \cmd{EXIT} has no effect and displays nothing.
\Example
At the \texttt{A:\bs>} prompt of a freshly started system, type
\type{EXIT} and press \key{Enter}.  The prompt is displayed again, because
the command processor started with the system is permanent.
\end{DosEntry}

% UG pp.66-71: 1 create primary only, 2 change active, 3 delete primary only,

% ruling).  WL-0141.  Shipped as DOS\FDISK.COM.  Gates: test-fdisk,
% test-fdisk-emu.
\begin{DosEntry}{FDISK}{Fixed Disk}{external}
\Purpose Creates, deletes, activates and displays the DOS partition of a
fixed disk.
\Format \SyntaxLine{\opt{\ph{d}\kw{:}}\opt{\ph{path}}\kw{FDISK}}
\Type{External}
\Remarks
\cmd{FDISK} displays the \textbf{Disk Options} menu for the first fixed disk.
Type the number of an option and press \key{Enter}; \key{Enter} alone takes
the number shown in brackets.  \key{Esc} returns from any screen to the
menu, and from the menu to the command prompt.

\Param{1. Create DOS Partition} creates the primary DOS partition, if the
disk has none: either the largest free space, made active, or a number of
cylinders you type.  Extended partitions cannot be created in this version.

\Param{2. Change Active Partition} makes the partition whose number you
type the one the system starts from.

\Param{3. Delete DOS Partition} deletes the primary DOS partition after you
answer \type{Y} to the warning; the default answer is \type{N}.  Extended
partitions and logical drives cannot be deleted in this version.

\Param{4. Display Partition Data} lists each partition with its status
(\texttt{A} for active), type, first and last cylinder and size.

\Param{5. Select Next Fixed Disk Drive} appears only when the system has a
second fixed disk.

When a partition has been changed, \cmd{FDISK} displays
\texttt{System will now restart} and asks you to insert the DOS diskette and
press a key.  The disk that holds the files you are using is never changed:
\cmd{FDISK} ends at once if it is selected.
\Example
Type \type{FDISK} and press \key{Enter}.  Type \type{4} and press
\key{Enter} to display the partitions, then press \key{Esc} twice to return
to the command prompt.
\end{DosEntry}

% FORMAT -- os/milton/diskutil.c format_run (MS-DOS 3.3 UG pp.74-76,
% 332-337: /S /V /B /1 /4 /8 /T: /N:, /B not with /S or /V; the running
% volume refused; diskette prompt; fixed disk label check and warning;
% "Formatting...", "Format complete", "System transferred", the report;
% "Format another (Y/N)?" for diskettes; one sector per cluster in this
% version).  System files from drive C (DEC-18).  WL-0147.  Shipped as
% DOS\FORMAT.COM.  Gates: test-formatsys, test-formatsys-emu,
% test-format-system-boot.
\begin{DosEntry}{FORMAT}{}{external}
\Purpose Prepares a disk for use by InitechDOS, erasing everything on it.
\Format \SyntaxLine{\opt{\ph{d}\kw{:}}\opt{\ph{path}}\kw{FORMAT} \ph{d}\kw{:}
  \opt{\kw{/S}} \opt{\kw{/V}} \opt{\kw{/B}} \opt{\kw{/1}} \opt{\kw{/4}}
  \opt{\kw{/8}} \opt{\kw{/T:}\ph{tracks}} \opt{\kw{/N:}\ph{sectors}}}
\Type{External}
\Remarks
\Param{d:} is the drive to format; it is required.  The disk that holds the
files you are using cannot be formatted: \cmd{FORMAT} displays
\texttt{Format not supported on drive} \ph{d}\texttt{:}.  Drive~B does not
exist in this version.

For a diskette, \cmd{FORMAT} asks you to insert a new diskette and press
\key{Enter}.  For a fixed disk, it first asks for the current volume label
(type it exactly; a different label ends \cmd{FORMAT} with
\texttt{Invalid Volume ID Format failure}), then warns that all data will
be lost and asks \texttt{Proceed with Format (Y/N)?}.

\cmd{FORMAT} writes a new boot record, two empty file allocation tables and
an empty root directory, and displays \texttt{Format complete} and the
total and available space.  For a diskette it then asks
\texttt{Format another (Y/N)?}.  This version uses one sector per cluster;
a disk too large for that displays \texttt{Format requires more than one
sector per cluster}.

\Param{/S} copies the system files and \file{COMMAND.COM} from drive~C to
the new disk and displays \texttt{System transferred}; the disk can then
start the system.  \Param{/V} asks for a volume label.  \Param{/B} reserves
room for the system files, which \cmd{SYS} can add later; it cannot be used
with \kw{/S} or \kw{/V}.

\Param{/1} formats only one side of a diskette.

\Param{/4} formats a 40-track diskette.

\Param{/8} formats eight sectors per track.

\Param{/T:} gives the number of tracks, and \kw{/N:} the number of sectors
per track.

\kw{/1}, \kw{/4}, \kw{/8}, \kw{/T:}, \kw{/N:} and \kw{/B} are for
diskettes only.  Any other switch displays \texttt{Invalid parameter}.
\Example
Drive~A holds the files you are using, so it cannot be formatted.  Type
\type{FORMAT A:}; \cmd{FORMAT} displays \texttt{Format not supported on
drive A:} and nothing is changed.
\end{DosEntry}

\begin{DosEntry}{LABEL}{Volume Label}{external}
\Purpose Creates, changes or deletes the volume label of a disk.
\Format \SyntaxLine{\opt{\ph{d}\kw{:}}\opt{\ph{path}}\kw{LABEL}
  \opt{\ph{d}\kw{:}}\opt{\ph{label}}}
\Type{External}
\Remarks
\Param{d:} is the drive of the disk.  You can specify any mounted drive.
If you omit it, the current drive is used.  Selecting a drive here does
not change the current drive.  An invalid drive letter displays
\texttt{Invalid drive specification}.

\Param{label} is the new volume label, up to 11 characters.  Letters are
changed to capitals; characters after the eleventh are ignored.  A label
may contain spaces, but not the characters
\texttt{* ? / \textbackslash{} | . , ; : + = < > [ ] ( ) \& \textasciicircum{} "};
\cmd{LABEL} displays \texttt{Invalid characters in volume label} and

\texttt{has no label}) and asks for a new one:
\begin{TypeIn}

and the disk has a label, \cmd{LABEL} asks

label; any other answer keeps it.

The label is shown by \cmd{DIR}, \cmd{VOL}, \cmd{CHKDSK} and \cmd{TREE}.
If the root directory has no room for the label, \cmd{LABEL} displays
\texttt{No room in root directory}.

\begin{DosEntry}{REN}{Rename}{internal}
\AlsoNamed{RENAME}
\Purpose Changes the name of a file.
\Format \SyntaxLine{\kw{REN} \opt{\ph{d}\kw{:}}\opt{\ph{path}}\ph{filename}\opt{\kw{.}\ph{ext}}
  \ph{filename}\opt{\kw{.}\ph{ext}}}
  \SyntaxLine{\kw{RENAME} \opt{\ph{d}\kw{:}}\opt{\ph{path}}\ph{filename}\opt{\kw{.}\ph{ext}}
  \ph{filename}\opt{\kw{.}\ph{ext}}}
\Type{Internal}
\Remarks
The first file specification names the file to rename.  The second is the
new name; do not give it a drive or path.  The file stays in \Slip{VO30-06}{it's} directory.

You can use wildcards in both names.  Every file that matches the first name
is renamed; where the new name has a \type{?} or \type{*}, the character in
that position of the old name is kept.  \texttt{REN *.TXT *.OLD} changes the
extension of every \file{.TXT} file in the directory.

\cmd{REN} displays nothing when it succeeds.  If no file matches the first
name, or a file with the new name already exists, \cmd{REN} displays
\texttt{Duplicate file name}; with wildcards, the other files are still
renamed.  If the new name has a path, it displays
\texttt{Bad command or file name}.  With only one name it displays
\texttt{Required parameter missing}.
\Example
To rename \file{MEMO.TXT} to \file{MEMO.OLD} and list the directory:
\Shot{ren}
\end{DosEntry}
