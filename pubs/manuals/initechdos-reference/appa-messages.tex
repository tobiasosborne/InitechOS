\section{How to Use This Appendix}
This appendix lists the messages InitechDOS displays.  Each message is shown
exactly as it appears on the screen, followed by an explanation of what it
means and the action you should take.  Where a message names a drive, the
letter \ph{d} stands for the drive letter.  The number beside each message
identifies it when you call the Help Desk (extension 2504).

The device error messages come first.  The other messages follow in
alphabetical order, and then the messages that individual commands display.

\section{Responses}
When InitechDOS cannot read or write a disk, it displays a device error
message and asks \texttt{Abort, Retry, Fail?}  Press one of these letters;
you need not press \key{Enter}:

\SideHead{A (Abort)}Ends the program that was using the disk and returns to
the command prompt.

\SideHead{R (Retry)}Tries the operation again.  Correct the cause first,
for example by closing the drive door.

\SideHead{F (Fail)}Tells the program that the operation failed and lets it
continue.  The program decides what to do next.

Any other key displays the question again.

\section{Device Error Messages}
\MessageDetail{MSG-DOS-0001}{InitechDOS could not read or write a disk and
asks what to do.  It is displayed after a device error message.}{Press
\type{R} to try again after correcting the problem, \type{A} to end the
program, or \type{F} to let the program continue.}
\MessageDetail{MSG-DOS-0007}{InitechDOS could not read the disk in drive
\ph{d}.  \cmd{DIR} displays this message when it cannot read the volume
label of the disk.}{Make sure the disk is formatted and seated in the drive,
then try the command again.  If the message persists, the disk may be
damaged; copy the files you can read to another disk.}
\MessageDetail{MSG-DOS-0006}{The drive \ph{d} was not ready: the door may be
open or the drive may be empty.\draft{see bead initech-vlhp: catalogue entry not displayed by any
code path of this version}}{Put a disk in the drive, close the door, and
press \type{R}.}
\MessageDetail{MSG-DOS-0008}{InitechDOS tried to write on a disk in drive
\ph{d} that is write-protected.\draft{see bead initech-vlhp: catalogue entry not displayed by any
code path of this version}}{Remove the write protection, or use another
disk, and press \type{R}.}

\section{Other Messages Displayed by Commands}
These messages are displayed by particular commands.  The command is shown
at the right.

\OtherMessage{All specified file(s) are contiguous}{CHKDSK}{Every file you
named is stored in one piece.}{None.}
\OtherMessage{Batch nesting too deep}{CALL}{Batch files have called each
other too many times without ending.}{Reduce the number of nested
\cmd{CALL} subcommands.}
\OtherMessage{Cannot edit .BAK file--rename file}{EDLIN}{\cmd{EDLIN} does
not edit backup files.}{Rename the file with \cmd{REN} and edit it under
the new name.}
\OtherMessage{Cannot perform a cyclic copy}{XCOPY}{You asked \cmd{XCOPY} to
copy a directory, with its subdirectories, into itself or into one of its
own subdirectories.}{Copy the directory to a place outside it.}
\OtherMessage{Corrections will not be written to disk}{CHKDSK}{\cmd{CHKDSK}
found errors, but you did not give \kw{/F}, so nothing was changed.}{Run
\cmd{CHKDSK /F} to correct the errors.}
\OtherMessage{Disk error reading (or writing) FAT}{CHKDSK}{\cmd{CHKDSK}
could not read the file allocation table, or the disk is not formatted as
InitechDOS expects.}{Copy the files you can read to another disk.}
\OtherMessage{Disk full - file write not completed}{EDLIN}{The disk filled
while \cmd{EDLIN} was writing the file.  The original file is
unchanged.}{Make room on the disk, or quit with \kw{Q}.}
\OtherMessage{Entry error}{EDLIN}{The command line is not a valid
\cmd{EDLIN} command: an unknown letter, a line number out of range, or
lines that overlap the destination of \kw{C} or \kw{M}.}{Type the command
again.}
\OtherMessage{Environment variable not defined}{SET}{The variable you named
is not in the environment.}{Use \cmd{SET} alone to list the variables.}
\OtherMessage{File access denied}{EDLIN}{\cmd{EDLIN} could not read, create
or rename a file, for example because a file is read-only.}{Check the
file's attributes with \cmd{ATTRIB}.}
\OtherMessage{File creation error}{CHKDSK}{\cmd{CHKDSK /F} could not create
a \file{FILE}\ph{nnnn}\file{.CHK} file for a lost chain, usually because the
root directory is full.}{Delete or move files from the root directory and
run \cmd{CHKDSK /F} again.}
\OtherMessage{Insufficient memory}{EDLIN}{The lines do not fit in memory.}
{Write part of the file to disk with \kw{W}, then go on.}
\OtherMessage{Invalid characters in volume label}{LABEL}{The label contains
a character that is not allowed, or has no characters.}{Type a label of
letters, digits and spaces.}
\OtherMessage{Invalid date}{DATE, start-up}{The date is not a real date, or is not in
the form \ph{mm}\texttt{-}\ph{dd}\texttt{-}\ph{yy}.  The date was not
changed.}{Type the command again with a valid date.}
\OtherMessage{Invalid number of parameters}{ATTRIB, TREE, XCOPY}{The
command has too many or too few file names.}{Check the Format line of the
command.}
\OtherMessage{Invalid parameter}{CHKDSK}{A switch other than \kw{/F} or
\kw{/V}, or more than one file name, was given.}{Check the Format line of
\cmd{CHKDSK}.}
\OtherMessage{Invalid parameter(s)}{TREE, XCOPY}{A switch is not one the
command accepts, or the switches cannot be used together.}{Check the Format

\OtherMessage{Invalid path (or file not found)}{ATTRIB, TREE, XCOPY}{The
file or directory does not exist, or a directory was named where a file was

\OtherMessage{Invalid time}{TIME, start-up}{The time is not in the form

\OtherMessage{Label not found}{GOTO}{The batch file has no label of the name

\OtherMessage{Line too long}{EDLIN}{A replacement would make the line longer

\OtherMessage{No Path}{PATH}{No search path is set: only the current

\OtherMessage{No room in root directory}{LABEL}{The root directory has no

\OtherMessage{Not found}{EDLIN}{\kw{S} or \kw{R} found no match in the

\OtherMessage{Out of environment space}{SET, PROMPT, PATH}{The environment has no

\OtherMessage{Strike a key when ready . . .}{PAUSE}{A batch file is paused at
