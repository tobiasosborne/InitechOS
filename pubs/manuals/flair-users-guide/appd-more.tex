\section{The InitechDOS books}
The \doctitle{InitechDOS User's Guide} (1024-3300-11) teaches the command
prompt; the \doctitle{InitechDOS Reference} (1024-3300-10) describes every
command and message.

\section{The application books}
Initech 123, InitechWord, InitechBase and the TPS Report Generator each come
with their own books.  Ask your Initech representative for copies.

\section{The Help Desk}
Call the Initech Help Desk at extension 2504.  Before you call, write down
any message on the screen, and the first line of \menuitem{About This
Computer...} in the Apple menu.
