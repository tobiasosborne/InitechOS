\GlossaryTerm{accessory}A small application listed in the Apple menu, so
that it can be opened from any application.  The Calculator is an
accessory.

\GlossaryTerm{active application}The application whose menus are in the
lower menu bar: the one whose window is in front, or the Finder.

\GlossaryTerm{active window}The front window, the one you are working in.
Its title bar is striped.

\GlossaryTerm{alert box}A box in which FLAIR or an application tells you
something or asks you to confirm an action, with one or more buttons.

\GlossaryTerm{Apple menu}The menu at the left end of the upper menu bar,
with About This Computer and the accessories.

\GlossaryTerm{application}A program you use to do your work, such as
InitechText.  An application on the disk has a name ending in
\file{.EXE} and a diamond for its icon.

\GlossaryTerm{Arrange (by Name)}A View menu command that lays out the
icons of the active Finder window in alphabetical order.

\GlossaryTerm{button}A labelled outline in an alert or dialog box that you
click to give an answer, such as \texttt{OK} or \texttt{Cancel}.  See also
\textbf{default button}.

\GlossaryTerm{Clean Up}A command that moves the icons of the active Finder
window into tidy rows.

\GlossaryTerm{click}To press and quickly release the mouse button while the
pointer is on something.

\GlossaryTerm{Clipboard}The place in memory where Cut and Copy put the
selected text, and from which Paste takes it.

\GlossaryTerm{close box}The small square at the left end of a title bar;
clicking it closes the window.

\GlossaryTerm{collapse box}The box at the right end of a title bar;
clicking it rolls the window up into its title bar.

\GlossaryTerm{command}An instruction you give by choosing it from a menu,
or with its keyboard equivalent.

\GlossaryTerm{command prompt}The \texttt{A:\textbackslash>} that InitechDOS
shows when it is waiting for a command, after you leave FLAIR with
\menuitem{Exit to InitechDOS}.

\GlossaryTerm{data disk}The disk that holds your files and the
applications, shown on the desktop as the \texttt{INITECH} icon.

\GlossaryTerm{default button}The button with the heavy border in an alert
or dialog box, chosen by pressing \key{Enter}.

\GlossaryTerm{desktop}The working area that fills the screen, on which the
icons and windows lie.

\GlossaryTerm{Desktop button}The button of the Open and Save dialog boxes
that lists the top level of the disk.

\GlossaryTerm{DESKTOP.DB}The file on the data disk in which FLAIR records
the places of the desktop icons and of the Finder windows.  It is not
shown in the Finder's windows.

\GlossaryTerm{dialog box}A box in which an application asks you for
information, such as the name of a document.

\GlossaryTerm{dimmed}Drawn in grey, and not available.  A dimmed command
cannot be chosen.

\GlossaryTerm{directory}The InitechDOS word for a folder.

\GlossaryTerm{document}A file of information that you create with an
application.

\GlossaryTerm{double-click}To click twice in quick succession without
moving the mouse.  Double-clicking an icon opens it.

\GlossaryTerm{drag}To move the mouse while holding down its button, then
release the button.

\GlossaryTerm{drive A}The name InitechDOS gives the data disk.  The
\texttt{Drive A Files} window shows its top level.

\GlossaryTerm{Empty Trash}The Special menu command that deletes everything
in the Trash from the disk.

\GlossaryTerm{Exit to InitechDOS}The Special menu command that leaves FLAIR
for the InitechDOS command prompt.

\GlossaryTerm{extension}The one to three characters after the period in a
file name, such as \file{TXT} in \file{README.TXT}.

\GlossaryTerm{file}A named collection of information on a disk: a
document or a program.

\GlossaryTerm{file name}The name of a file as InitechDOS stores it: one to
eight characters, then, if wanted, a period and one to three more.

\GlossaryTerm{Finder}The part of FLAIR that shows the disk, folders and
files and lets you organize them.

\GlossaryTerm{folder}A container on the disk for files and other folders.
InitechDOS calls a folder a directory.

\GlossaryTerm{HELLO}One of the two practice applications built into
FLAIR; its window is open when FLAIR starts.

\GlossaryTerm{hourglass pointer}See \textbf{pointer}.

\GlossaryTerm{icon}A small picture that stands for a disk, a folder, a file
or the Trash.

\GlossaryTerm{InitechDOS}The operating system on which FLAIR runs.

\GlossaryTerm{insertion point}The place in a document where what you type
appears, shown as a thin vertical line.

\GlossaryTerm{keyboard equivalent}A combination of \key{Ctrl} and a letter
that chooses a menu command.  A menu shows it as a caret and the letter.

\GlossaryTerm{locked}Of a file: marked so that it cannot be changed or
thrown away.  InitechDOS calls such a file read-only.

\GlossaryTerm{lower menu bar}The second menu bar, which shows the menus of
the active application.

\GlossaryTerm{menu}A list of commands that drops down from its title in a
menu bar.

\GlossaryTerm{menu bar}One of the two bars across the top of the screen
that hold the menu titles.  The upper bar is FLAIR's own; the lower bar
belongs to the active application.

\GlossaryTerm{New Folder}The File menu command that makes an empty folder
in the active Finder window.

\GlossaryTerm{NOTES}One of the two practice applications built into
FLAIR; its window is open when FLAIR starts.

\GlossaryTerm{point}To move the mouse until the tip of the pointer is on
something.

\GlossaryTerm{pointer}The arrow on the screen that moves when you move the
mouse.

\GlossaryTerm{progress box}A box that an application shows while it works,
with a bar that fills as the work goes on.

\GlossaryTerm{read-only}The InitechDOS word for a locked file.  See
\textbf{locked}.

\GlossaryTerm{Restart}The Special menu command that saves the arrangement
of the desktop and starts the computer again.

\GlossaryTerm{Save As}The command that saves a copy of a document under a
new name; the window then shows the copy.

\GlossaryTerm{scroll bar}The bar along the right side or the bottom of a
window, used to bring the rest of the window's contents into view.

\GlossaryTerm{scroll box}The small square in a scroll bar that shows which
part of the contents is in view.

\GlossaryTerm{select}To mark something, usually by clicking it, as the
thing the next command acts on.  A selected icon is drawn in reverse.

\GlossaryTerm{selection rectangle}The rectangle you drag from a bare part
of a Finder window to select the icons inside it.

\GlossaryTerm{Shut Down}The Special menu command that prepares the
computer to be turned off.

\GlossaryTerm{size box}The square at the lower right corner of a window;
dragging it changes the size of the window.

\GlossaryTerm{startup disk}The disk from which the computer loads
InitechDOS and FLAIR.

\GlossaryTerm{title bar}The bar across the top of a window, holding its
name and boxes; dragging it moves the window.

\GlossaryTerm{top level}The part of a disk outside every folder: what the
\texttt{Drive A Files} window shows.

\GlossaryTerm{Trash}The icon at the bottom right of the desktop, where you
put files and folders to throw them away.  See also \textbf{Empty Trash}
in the index.

\GlossaryTerm{upper menu bar}The first menu bar, which belongs to FLAIR
itself, with the Apple menu and the clock.

\GlossaryTerm{volume label}The name stored on a disk, shown under its icon
on the desktop.  Change it with \file{LABEL} at the InitechDOS prompt.

\GlossaryTerm{window}A framed area on the screen that shows the contents of
a disk, a folder or a document.

\GlossaryTerm{zoom box}The first box at the right end of a title bar;
clicking it makes the window fill the screen.
