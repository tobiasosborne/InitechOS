\chapter{What FLAIR Needs}
\index{system requirements}
To use FLAIR you need:
\begin{itemize}
\item An Initech workstation or a compatible personal computer with an
  Intel 80486 microprocessor.  A math coprocessor is not needed for FLAIR;
  Initech 123 needs one.
\item At least 5~MB of memory: the first megabyte and 4~MB of extended
  memory above it.
\item A VGA display adapter with the VESA BIOS Extensions, Version~2.0, able
  to show 640 by 480 dots in 256 colours, and a VGA monitor.
\item A keyboard and a mouse, connected to the computer's keyboard and
  mouse ports.
\item A disk drive with an AT-compatible (ATA) controller for the startup
  disk, and a second drive for the data disk.
\end{itemize}
FLAIR checks the memory and the display when it starts, and stops with a
\texttt{PC LOAD LETTER} message if either is not enough (Chapter~\ref{ch:trouble}).
