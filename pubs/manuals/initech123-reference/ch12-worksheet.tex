\chapter[The Worksheet Commands]{\textit{The Worksheet Commands}}

The Worksheet commands control the worksheet as a whole: the settings that
apply to every cell, the widths of columns, the way formulas are
recalculated, protection, and erasing the worksheet.

\begin{LotTable}{p{36mm}p{92mm}}
\LotHead{\textbf{Command} & \textbf{Task}}
/Worksheet Global & Sets the format, label prefix, column width,
  recalculation and protection of the whole worksheet\\
/Worksheet Insert & Inserts columns or rows \draft{I123-P3-01: its commands refuse}\\
/Worksheet Delete & Deletes columns or rows \draft{I123-P3-01: its commands refuse}\\
/Worksheet Column & Sets the width of the current column\\
/Worksheet Erase & Erases the worksheet from memory\\
/Worksheet Titles & Freezes rows or columns on the screen \draft{I123-P3-01: its commands refuse}\\
/Worksheet Window & Splits the screen \draft{I123-P3-01: its commands refuse}\\
/Worksheet Status & Displays the worksheet settings \draft{I123-P3-01: refuses}\\
/Worksheet Page & Inserts a page break \draft{I123-P3-01: refuses}\\
/Worksheet Learn & Records keystrokes \draft{I123-P3-01: its commands refuse}\LotEnd
\end{LotTable}

\section{Common Uses of the Worksheet Commands}
\begin{itemize}
\item Displaying every number of a worksheet with two decimal places
  (\slashcmd{/Worksheet Global Format Fixed})
\item Making every column wider at once
  (\slashcmd{/Worksheet Global Column-Width})
\item Making one column wider (\slashcmd{/Worksheet Column Set-Width})
\item Recalculating only when you press CALC (F9) in a large worksheet
  (\slashcmd{/Worksheet Global Recalculation Manual})
\item Protecting a finished worksheet from accidental change
  (\slashcmd{/Worksheet Global Protection Enable})
\item Starting again with an empty worksheet (\slashcmd{/Worksheet Erase
  Yes})
\end{itemize}

\section{Terms You Need to Know}
\begin{itemize}
\item A \term{global setting} applies to every cell that has no setting of
  its own.  A new worksheet has the global format General, the global
  column width 9, the label prefix \texttt{'} (left-aligned), and natural,
  automatic recalculation.
\item The \term{recalculation order} is the order in which Initech 123
  calculates the formulas of the worksheet.
\end{itemize}

\MenuEntry{/Worksheet}
/Worksheet displays the Worksheet menu.

\MenuEntry{/Worksheet Global}
/Worksheet Global displays the menu of the global settings.  Every global
setting is saved with the worksheet.
\begin{Options}
\OptionMenu{Format} Sets the global format (below).
\OptionMenu{Label-Prefix} Sets the label prefix for new labels (below).
\Option{Column-Width} Sets the width of every column that has no width of
  its own.  At \texttt{Enter global column width (1..240):} type a number
  from 1 to 240 and press \kname{ENTER}.
\OptionMenu{Recalculation} Sets when and in what order formulas are
  recalculated (below).
\OptionMenu{Protection} Turns worksheet protection on or off (below).
\OptionMenu{Default} Displays the Default menu (below).
\Option[I123-P3-01: refuses]{Zero} Sets whether cells whose value is zero
  appear empty.
\end{Options}

\SubEntry{/Worksheet Global Format}
/Worksheet Global Format sets the format of every cell not given one with
\slashcmd{/Range Format}.  The formats are those of /Range Format
(Chapter~10), without Reset.  For Fixed, Sci, Currency, the comma format
and Percent, Initech 123 asks \texttt{Enter number of decimal places
(0..15):}.
\begin{Options}
\Option{Fixed} A fixed number of decimal places.
\Option{Sci} Scientific notation.
\Option{Currency} A dollar sign, commas and a fixed number of decimal
  places.
\Option{,} Commas between thousands and a fixed number of decimal places.
\Option{General} As many decimal places as fit (the format of a new
  worksheet).
\Option{+/-} A bar of plus or minus signs.
\Option{Percent} A percentage.
\OptionMenu{Date} Displays the Date menu (below).
\Option{Text} Formulas instead of their values.
\Option{Hidden} Nothing.
\end{Options}

\Option[I123-P3-05: refuses]{5 (Short Intn'l)} The international short date.

\SubEntry{/Worksheet Global Label-Prefix}
Sets the prefix Initech 123 gives a label you type without one.  Labels
already in the worksheet keep their prefixes; to change them use
\slashcmd{/Range Label}.
\begin{Options}
\Option{Left} New labels are left-aligned (\texttt{'}).
\Option{Right} New labels are right-aligned (\texttt{"}).
\Option{Center} New labels are centered (\texttt{\textasciicircum}).
\end{Options}

\SubEntry{/Worksheet Global Recalculation}
Sets when Initech 123 recalculates formulas and in what order.  While
recalculation is automatic, selecting a setting recalculates the worksheet
at once.
\begin{Options}
\Option{Natural} Calculates every formula after the formulas it depends
  on (the setting of a new worksheet).
\Option{Columnwise} Calculates column by column, from A1 down column A,
  then down column B, and so on.
\Option{Rowwise} Calculates row by row, from A1 across row 1, then across
  row 2, and so on.
\Option{Automatic} Recalculates after every entry (the setting of a new
  worksheet).
\Option{Manual} Recalculates only when you press \fkey{Calc}{F9}; the
  \ind{CALC} indicator shows when the worksheet needs it.
\Option{Iteration} Sets how many times a recalculation passes through the
  worksheet while it contains a circular reference.  At \texttt{Enter
  iteration count (1..50):} type a number from 1 to 50.  A worksheet
  without a circular reference is calculated once in natural order.
\end{Options}

\begin{Note}
In Columnwise and Rowwise order a formula may be calculated before a
formula it depends on.  Recalculate again, with \fkey{Calc}{F9}, until the
values no longer change, or use Natural order.
\end{Note}

Manual recalculation: after A1 changes from 10 to 50, A2 keeps its old
value until CALC (F9) is pressed.

\SubEntry{/Worksheet Global Protection}
\begin{Options}
\Option{Enable} Turns worksheet protection on: protected cells cannot be
  changed by typing or by commands.  Cells are protected unless you have
  unprotected them with \slashcmd{/Range Unprot}.
\Option{Disable} Turns worksheet protection off.
\end{Options}

\MenuEntry{/Worksheet Column}
/Worksheet Column sets the width of the column the cell pointer is in.
\FlairShot[fig:colwidth]{colwidth}{Column A set to 12 characters}
\begin{Options}
\Option{Set-Width} At \texttt{Enter column width (1..240):} type a number
  from 1 to 240 and press \kname{ENTER}.  The width of a column is the
  number of characters it shows.
\Option{Reset-Width} Returns the column to the global column width.
\Option[I123-P3-01: refuses]{Hide} Hides a range of columns.
\Option[I123-P3-01: refuses]{Display} Displays hidden columns again.
\OptionMenu{Column-Range} Displays the Column-Range menu (below).
\end{Options}
\SubEntry{/Worksheet Column Column-Range}
\begin{Options}
\Option[I123-P3-01: refuses]{Set-Width} Sets the width of a range of
  columns.
\Option[I123-P3-01: refuses]{Reset-Width} Returns a range of columns to the
  global width.
\end{Options}
\begin{Note}
A width outside 1 to 240, or anything but a whole number, displays
\texttt{Illegal number}.
\end{Note}

\MenuEntry{/Worksheet Erase}
/Worksheet Erase clears the worksheet from memory, with every entry and
setting, and starts a new worksheet.
\begin{Options}
\Option{No} Returns to \ind{READY} mode; nothing is erased.
\Option{Yes} Erases the worksheet.
\end{Options}
\begin{Caution}
/Worksheet Erase Yes does not ask whether to save the worksheet first.
Save it with \slashcmd{/File Save} before you erase it.  The worksheet
file on disk is not affected.
\end{Caution}

\MenuEntry{/Worksheet Titles}

\begin{Options}

\Option[I123-P3-01: refuses]{Vertical} Freezes the columns to the left of
