\FrontChapter{Preface}
This book is the operating procedure for the TPS Report Generator,
\file{TPSREP.COM}, and the reference for the files, messages and forms that
belong to it.  It is written as a self-study course.  Each session
introduces one part of the operating procedure, states what you will be
able to do when you have completed it, gives the procedure in numbered
steps, and ends with a lab project and study questions.  Complete the
sessions in order.

\section{Getting Started}
Before you begin:
\begin{enumerate}
\item Make sure that this is the current edition.  The edition and the
  part number are printed on the back of the title page.  Your supervisor
  keeps the current edition list.
\item Obtain the materials listed below.  If an item is missing, see your
  supervisor before you continue.
\item Arrange a session at an InitechOS workstation on which the FLAIR
  desktop is running and the shipped data volume is drive A.  The
  procedures in this book are carried out at that workstation.
\end{enumerate}

form stand for information you supply.

\SideHead{Screens}The screens and transcripts in this book are
reproductions of the InitechOS display exactly as it appeared when each
procedure was carried out on a workstation with the shipped data volume,

\section{Course Description}
The course teaches the operating procedure of the TPS Report Generator in
seven sessions:

\SideHead{Session 1}The TPS Report Generator: the program, its files, the
parameter record, the TPS table, the report and the return codes.

\SideHead{Session 2}Leaving FLAIR: \proc{01}, the exit from the FLAIR
desktop to the InitechDOS prompt.

\SideHead{Session 3}Preparing the Run: \proc{02}, the parameter record
(Operating Procedure OP-7.3).

\SideHead{Session 4}Aligning the Form: \proc{03}.

\SideHead{Session 5}The Report Number and the Memo: \proc{04} and
\proc{05}.

\SideHead{Session 6}The Cover Sheet and the Records Retained: \proc{06} and
\proc{07}.

\SideHead{Session 7}Refusals and Faults: \proc{08} and the escalation
checklist.

The appendices hold the Operator Course Evaluation, the terminal
procedures, the answers to the study questions, a review of the InitechDOS
commands used, the final quiz, the data collection sheets and the messages.

\section{Prerequisite}
You should be able to use the mouse and the menus of the FLAIR desktop and
to type a command at the InitechDOS prompt.  The \doctitle{InitechDOS
User's Guide} (1024-3300-11) teaches both.  No knowledge of the TPS table
or of programming is needed.

\section{Duties and Tasks}
Upon completion of this course you will be able to:
\begin{enumerate}
\item Leave the FLAIR desktop for the InitechDOS prompt and make the
  directory that holds the TPS Report Generator the current directory.
\item Verify the parameter record before a run.
\item Align the form as the program requires.
\item Key the report number twice and record it in the report number
  control log.
\item Acknowledge the memo about the new cover sheets and record it in the
  memo acknowledgement log.
\item Attest that the new cover sheet is attached.
\item Verify and retain the report and the previous report.
\item Identify each message of the program, take the action it requires,
  and escalate to your supervisor where the procedure says so.
\end{enumerate}
