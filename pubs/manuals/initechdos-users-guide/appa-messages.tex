\chapter{Messages}
This appendix lists, in alphabetical order, the messages that InitechDOS
displays.  Each message is shown exactly as it appears on the screen.  Where
a message names a drive, \ph{d} stands for the drive letter.  The number beside
each message identifies the message when you call the Help Desk
(extension 2504).
