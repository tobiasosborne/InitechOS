\FrontChapter{About This Book}
This book shows you how to start InitechDOS, how to give it commands, and
how to look after the files you keep on your disks.  It is written for
people who have not used a personal computer operating system before, and
for experienced users who are new to InitechDOS.  You do not need to know
anything about programming.

\section{Read This First}
Before you begin, make sure your computer has been set up as described in
the instructions that came with it, and that you have the InitechDOS
diskettes from the package.  Keep this book beside your computer while you
work: most chapters are written as short exercises that you carry out as you
read.

\section{First-Time Users}
Read Chapters 1 and 2 in order and do every exercise in Chapter~2.  Then
read the other chapters as you need them.  When you want the exact form of a
command, look it up in the \doctitle{InitechDOS Reference}.

\section{Experienced Users}
Skim Chapter~1, then read the chapters on the subjects you need.  Chapter~9
introduces the utility programs; the \doctitle{InitechDOS Reference}
describes every command in full, including the places where InitechDOS
differs from what you may be used to.

\section{Terms Used}
\SideHead{Diskette}A flexible disk in a diskette drive.

\SideHead{Fixed disk}A disk that is built into the computer and cannot be
removed.

\SideHead{Disk}Either a diskette or a fixed disk.

\SideHead{Source}The disk, directory or file that information is copied
from.

\SideHead{Target}The disk, directory or file that information is copied
to.

\section{How This Book Is Organized}
\SideHead{Chapter 1}Introduction to InitechDOS explains what an operating
system does and introduces drives, files, directories and commands.

\SideHead{Chapter 2}Getting Started takes you from turning on the computer
to listing, displaying, copying and deleting files, and working with
directories.

\SideHead{Chapter 3}Working with Files and Directories covers file names,
wildcards, paths and the directory tree.

\SideHead{Chapter 4}Diskettes and the Fixed Disk covers volume labels,
checking a disk, and keeping backup copies of your files.

\SideHead{Chapter 5}Batch Files shows how to put commands in a file and
carry them out with one name, and describes \file{AUTOEXEC.BAT}.

\SideHead{Chapter 6}Configuring Your System describes \file{CONFIG.SYS},
the environment, and the command prompt.

\SideHead{Chapter 7}Redirecting Input and Output shows how to send the
output of a command to a file and take input from a file.

\SideHead{Chapter 8}The InitechDOS Editing Keys describes the keys you use
when you type a command.

\SideHead{Chapter 9}The Utility Programs introduces \cmd{ATTRIB},
\cmd{CHKDSK}, \cmd{LABEL}, \cmd{TREE} and \cmd{XCOPY}.

\SideHead{Appendix A}Messages lists the messages InitechDOS displays.

\SideHead{Appendix B}Glossary defines the terms used in this book.

An index and a Reader's Comment Form are at the back of the book.

\section{Conventions Used in This Book}
\SideHead{What you type}Text that you type is shown in this typeface:
\type{DIR}.  You may type commands in capital or small letters; InitechDOS
treats them the same.  Unless the text tells you otherwise, finish each
command by pressing \key{Enter}.

\SideHead{Keys}The names of keys are shown like this: \key{Enter},
\key{Backspace}, \key{Ctrl}.  \key{Ctrl-C} means: hold down \key{Ctrl},
press \key{C}, and release both keys.

\SideHead{Command forms}When this book shows the form of a command, words in
capital letters, such as \kw{COPY}, are typed exactly as shown.  Words in
\ph{italics} stand for information you supply, such as a file name.  Items
in square brackets \opt{\ph{like this}} are optional; do not type the
brackets.

\SideHead{Screens}Figures that show the display are reproductions of the
InitechDOS screen exactly as it appeared when the exercise was carried out,
with the system clock set to 9:30 a.m.\ on March~2, 1992.
