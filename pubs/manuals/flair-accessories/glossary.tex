\GlossaryTerm{About This Computer}The first command of the Apple menu: an
alert with the version of InitechDOS and the computer's memory.

\GlossaryTerm{accessory}A small application listed in the Apple menu, such
as the Calculator.

\GlossaryTerm{Apple menu}The menu at the left end of the upper menu bar,
which lists About This Computer and the accessories on the data disk.

\GlossaryTerm{application}A program you use to do your work, such as
InitechText.  Its name ends in \file{.EXE}.

\GlossaryTerm{canvas}The window of InitechPaint in which a picture is
drawn.

\GlossaryTerm{cell}A box of InitechCalc's ledger, named by its column and
row, which holds an item or an amount.

\GlossaryTerm{cell pointer}The black line above a cell of InitechCalc's
ledger that shows which cell you are working in.

\GlossaryTerm{Clipboard}The place in memory where Cut and Copy put text and
from which Paste takes it.

\GlossaryTerm{display}The box at the top of the Calculator that shows the
number you type or the result.

\GlossaryTerm{document}A file you create with an application, such as a
memo written with InitechText.

\GlossaryTerm{entry line}The line of InitechCalc's ledger on which what
you type appears before you place it in a cell.

\GlossaryTerm{FILE COPY}The progress box InitechCalc shows while it saves
its tables.

\GlossaryTerm{insertion point}The place in a document where what you type
appears.

\GlossaryTerm{ledger}InitechCalc's table of items and amounts, with the
total of the quarter.

\GlossaryTerm{minus format}The way the ledger writes a negative amount,
with the minus sign at the end: \texttt{570-}.

\GlossaryTerm{pie chart}InitechCalc's picture of the quarter's shares as
the slices of a circle.

\GlossaryTerm{progress box}A box with a progress bar that an application
shows while it works, such as InitechCalc's \texttt{FILE COPY} box.

\GlossaryTerm{sample application}A small application that shows how an
application from the disk behaves: C Tenant and TenantFix.

\GlossaryTerm{Save As}The command that saves a document under a new name.

\GlossaryTerm{selection}The text that the next command acts on, shown
white on black.

\GlossaryTerm{text file}A file that holds only characters and line ends,
without type styles: what InitechText saves.
