## What the bytes show

All tags are `[verified: mint 004]` (the named file) unless marked otherwise.
The 111 TO FILE outputs listed below are reproduced byte-for-byte by the
InitechOS renderer; that differential is the cross-check of every rule here.

### Stream format
- Each output line is `CR LF` + text (the CR LF comes FIRST); the report ends
  with one more `CR LF`; `TO FILE` closes the file with `^Z` (0x1A). [G*.TXT]
- A page eject is `CR FF` (0x0D 0x0C). Default reports start with it; a form
  whose option byte 0x7C3 has bit 0 set (FLT_INFO) or `NOEJECT` starts without
  it. [G1FLT vs G2TRV, G5TRVH; resolves GAPS frm-3 for bit 0]
- `TO FILE` output == the console/ALTERNATE stream (R4ALOG.TXT) byte for byte;
  the screen shows the same text, the FF invisible: `Page No.  2` sits on the
  row right after `Pope` (R4S3.PNG). No pause between pages on screen
  (R4S2.PNG). Default extension `.TXT`.

### Page header (non-PLAIN)
- `lm` blanks + `Page No.` + STR(page,6); then `lm` + date (SET DATE / SET
  CENTURY format: `07/24/86`, `07/24/1986` under SET CENTURY ON [R4HC]).
- Title split on `;`; each line placed at `lm + (U - len) / 2` (integer
  division), `U = pagewidth - lm - rm`; an empty title line is that many
  blanks (TRAVELER: 40 blanks). Leading blanks of a piece are kept
  (` Flight schedules`). Proves 0x7BA = left margin and 0x7BC = right margin
  (TRAVELER centres in 70 = 80-5-5) and 0x7B8 = lines per page (the sweeps
  page exactly at nn). [resolves GAPS frm-1]
- One blank line, the column-heading band, then two blank lines.
- Heading band: each column heading split on `;` (a leading `;` gives an empty
  line); line i pads to each column start that has a piece i (empty pieces
  still pad: TRAVELER's two 68-blank lines); numeric columns right-align their
  heading in the width; text never pads after the last piece.
- `HEADING <expC>`: placed on the Page No. line at `lm + (U - len)/2 - 1`
  [G5TRVH, R4BHX, GCFH]; `;` splits it [R4HS]; a long one wraps like a C cell
  (`This is a very long heading that runs ` / `right across the page`, both
  centred by the same formula) [R4DH]. Wrap width: `[inferred]` one golden
  only, consistent with U-32..U-27. `HEADING ""` prints nothing [R4DE].
- `PLAIN`: no Page No./date lines; title + band on page 1 only; pages STILL
  eject (`CR FF`) at the page length, with no header after [G3TRVP, GDFP].

### Columns and cells
- Column c starts at `lm + sum(width[k] + 1, k < c)`.
- C values: right-trimmed, split at `;` (consumed), word-wrapped to the width
  by breaking after the last blank inside the width (the blank stays on the
  line), else a hard cut [R4DT: `aa ` / `bbbb...b ` / `cc`;
  `ABCDEFGHIJKLMNOPQRSTUVWXYZ` / `0123`; `Semi` / `colon split` / `here`];
  leading blanks kept. Continuation lines carry only the wrapped column.
- N: right-justified in the width with the .frm decimals (`3295.00` in 8).
- D: SET DATE text; L: `.T.` / `.F.` (dotted, unlike LIST's T/F).

### Groups and totals (TRIP.FRM: group `trip`, subgroup `date`, COST totalled)
- Group header `lm-1` blanks + `** ` + heading + ` ` + value (C value with its
  trailing blanks: `ALASKA    `); subgroup `* `. The first group header of a
  report follows the band's two blank lines directly; later ones get one blank
  line first; a subgroup header always gets a blank line under its group.
- Bands: `* Subsubtotal *`, `** Subtotal **`, `*** Total ***` at `lm-1`, each
  followed by one line with the sums under the totalled columns (same width /
  decimals; 152281.9 fits 8). The three end bands print even when FOR selects
  nothing (all 0.0) [R4HT].
- SUMMARY drops detail lines; headers and bands remain [G4TRVS, G9TS].
- Records are not sorted; a group break is any change between consecutive
  processed records (TRAVEL in natural order: one group per record) [G7TRVU].

### Paging (fitted exactly on 83 lpp sweeps: CTP14..40, CTS14..24, CTV18..40,
### CTL18..25, CFL11..24 -- one model reproduces every page break)
- Before each processed record: if the page already has >= lpp lines, eject.
- A unit of n lines needs n+1 free lines, else eject first: subtotal/total
  band n=2; one-level group header (blank + header) n=2; subgroup header n=2;
  a two-level group header (blank, `**`, blank, `*`) counts n=5.
- A header unit placed right after its own eject drops its leading blank; after
  a record-start eject it keeps it [G7TRVU page 4 vs page 2].
- A wrapped record is printed whole, even past lpp [CTP19 page 1 has 20 lines].
- Line counting continues from the SET ALTERNATE transcript when a report has
  no initial eject: with ALTERNATE ON the first page of a no-eject report can
  be header-only (R4BFB, R4BN, E5LOG); without ALTERNATE every report starts at
  line 0 (E1..E4 identical whatever came before). `[inferred]` exact counting
  rule beyond these cases.

### Scope and errors
- Default scope ALL (GO TOP). `WHILE` alone starts at the current record
  [R4DW]. `NEXT n` leaves the pointer ON the n-th record (R4ALOG: recno 17 =
  7th record of TRIPS order, EOF .F.); ALL ends at EOF.
- Headless no-database `REPORT FORM` hangs (dBASE prompts for a file) -- the
  error probes were dropped from R4B; the catalog texts (#50 Report file
  invalid, #52 No database is in USE) are the manual's/DBASE.MSG's.

## Still open
- frm-2: double-space / summary / eject Y/N flags (all `NNN`) -- untested.
- Option byte bits 1/2; numeric or logical group expressions; total overflow
  wider than the column; heading pieces of unequal count (top- vs bottom-
  aligned) -- no golden. The InitechOS renderer refuses or marks these.
