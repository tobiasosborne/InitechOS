105: \index{parameter record}\index{TPSPARM.DAT}
106: The parameter record \file{TPSPARM.DAT} is a text file of four lines.
107: Each line begins with its name, an equal sign, and the value; the value
108: runs to the end of the line.  The lines may be in any order.  The
109: parameter record on the shipped volume is:
110: 
111: \ReportLines[label=fig:parm, caption={The parameter record \file{TPSPARM.DAT} on the shipped volume.}]{../../../harness/diff/tps/tpsparm.dat}{1}{4}
112: 
113: \SideHead{TITLE=}The report title, printed centred on the cover sheet
114: under \texttt{T P S\ \ \ R E P O R T}.
115: 
116: \SideHead{DIVISION=}The division, printed on the cover sheet.
117: 
118: \SideHead{MEMO=}The number of the memo about the new cover sheets.  The
119: operator keys this number in \proc{05}; it is printed on the cover sheet
120: and in the totals.
121: 
122: \SideHead{LINES=}The number of detail lines on each page of the report.
123: A value of 0 is taken as 1.
124: 
125: A missing line is refused before anything else is done: the program
126: displays \TpsLine{TPS-002}{1}, with the name of the missing line, and
127: ends with return code 1.  The parameter record is maintained under
128: Operating Procedure OP-7.3, which is \proc{02} of this book.

130: \section{The TPS Table}
131: \index{TPS table}\index{TPS.DBF}
132: A TPS table is a dBASE III table with these six fields:
133: 
134: \begin{center}\small
135: \begin{tabular}{@{}llrp{46mm}@{}}
136: \rule{0pt}{10pt}\sffamily\bfseries Field & \sffamily\bfseries Type & \sffamily\bfseries Width & \sffamily\bfseries Contents\\\hline
137: \texttt{RPT\_NO} & Numeric & 6 & The number of the TPS report on file\\
138: \texttt{EMPLOYEE} & Character & 20 & The employee who filed it\\
139: \texttt{DEPT} & Character & 12 & The department\\
140: \texttt{PAGES} & Numeric & 3 & The number of pages filed\\
141: \texttt{COVER} & Logical & 1 & Whether the cover sheet was attached\\
142: \texttt{FILED} & Date & 8 & The date it was filed\\\hline
143: \end{tabular}\end{center}
144: 
145: A table without one of these fields is refused with \TpsLine{TPS-006}{1}
146: (return code 6).  A record marked for deletion is not listed.  The shipped
147: table \file{TPS.DBF} holds 14 records, one of them marked for deletion.
148: 
149: \section{The Report}
150: \index{report}\index{cover sheet}
151: The report has three parts.
152: 
153: \SideHead{Cover sheet}The cover sheet, \form{1} (Rev.\ 10/89), comes
154: first.  It carries the report number, the division, the name of the table,
155: the date the table was last updated, the tables on file in the current
156: directory, the memo number and the number of records in the table.
157: 
158: \ReportLines[label=fig:cover, caption={The cover sheet, as the program writes it to
159: \file{TPSREPT.TXT}.}]{../../../harness/diff/tps/tpsrept_expected.txt}{1}{17}
160: 
161: \SideHead{Detail pages}Each page begins with the report number and the
162: page number, then the column heads, then as many detail lines as the
163: \texttt{LINES=} line of the parameter record allows.  In \rpt\ each page
164: begins on a new sheet; on the screen a blank line separates the pages.
165: 
166: \ReportLines[caption={The first detail page (\texttt{LINES=6}).}]{../../../harness/diff/tps/tpsrept_expected.txt}{18}{26}
167: 
168: \SideHead{Totals}The totals give the reports listed, the pages filed and
169: the number of reports filed without a cover sheet.  When that number is
170: not zero, the totals end with the instruction to see the memo.

177: \TpsMsg{END}
178: where \ph{n} is the return code.
179: The return code can be tested in a batch file with \cmd{IF ERRORLEVEL}.

30: \index{report number}\index{report number control log}\index{Form TPS-2}\index{TPS-003@\texttt{TPS-003}}
31: The report number is assigned before the run and entered in \form{2},
32: column 1 (Checklist TPS-C-1).  It is one to six digits.  The program asks
33: for it with:
34: \TpsMsg{R3.prompt}
35: The first line is displayed first; when the first entry has been ended with
36: \key{Enter}, the second line is displayed.  Only the characters accepted are
37: displayed as they are typed.  After six characters, further keys are
38: ignored.  \key{Backspace} is ignored.
39: 
40: If the two entries do not agree, or are empty, the program displays:
41: \TpsMsg{TPS-003}
42: and asks for both entries again.  When they agree, the program continues
43: with the memo.  On the cover sheet and at the head of each page the report
44: number is printed with six digits, zeros first: report number 1014 is
45: printed \texttt{001014}.
