Function Keys

You use the function keys on your keyboard to perform special operations. Each
function key, except Fé, performs two operations: one when you press only the
function key, and another when you hold down ALT and then press the function
key. 1-2-3 functions keys are listed in the following table.

NOTE Although the documentation recommends using ALT in combination with
a function key to perform its second operation, you can use SHIFT instead. For
example, pressing SHIFT-F3 produces the same result as pressing ALT-F3 — it runs
a macro.
