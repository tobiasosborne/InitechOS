3. If you want to display files in a different drive and/or directory or with a
different extension, do one of the following:

¢ To display files with a different extension, type *. followed by another
extension and press ENTER.

* To display all files in the current directory, type *.* and press ENTER.

* To display files in a different drive and/or directory, press ESC to clear the

4. Specify the name of the file you want to retrieve and press ENTER.

5. If you are trying to retrieve a file shared on a network and someone else has

Yes Retrieves the file without the reservation; changes cannot be
saved to the same file name.

No Cancels the command without retrieving the file.

6. If the file on disk is password-protected, type the password and press ENTER.

You must type the same combination of uppercase and lowercase letters that

Tips
¢ If 1-2-3 does not have enough memory to read the file when you select /File

¢ if you make a mistake in the worksheet and want to start again with the

Retrieving a File Automatically

Normally, when you start 1-2-3, the program displays a blank worksheet on the
screen, You can, however, have 1-2-3 read a particular worksheet into memory
automatically every time you start the program.

To specify a worksheet for automatic file retrieval, use /File Save to save the
worksheet in a file named AUTO123.WK1 in the default directory (the directory
specified with /Worksheet Global Default Directory). The file must be saved in
the default directory so 1-2-3 can retrieve it at the beginning of each new session.

You can also retrieve a file when you start 1-2-3 by including a -w and the name
of the file on the operating system command line. For example, to retrieve a file
called JANUARY.WK1 in the current directory, you would type 123 -wjanuary.
