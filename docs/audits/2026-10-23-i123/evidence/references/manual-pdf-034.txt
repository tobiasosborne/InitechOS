Long Labels

When a label is longer than the cell’s column width, it is called a long label and
1-2-3 displays as much of the label as it can.

* If cells to the right of the label are blank, 1-2-3 displays the part of the label
that overlaps those cells.

¢ If cells to the right of the label contain data, 1-2-3 does not display the
overlapping part of the label.

In Figure 1-9, cell Al contains a long label that overlaps B1, 1-2-3 displays the
entire label because B1 is blank. Cell A6 also contains a long label, but because B6
contains an entry, 1-2-3 truncates the label so that it fits in A6. You can see that
A6 still contains the complete label by looking in the control panel.
