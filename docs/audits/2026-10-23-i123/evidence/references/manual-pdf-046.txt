Overriding Order of Precedence

You can override the order of precedence by enclosing an operation in
parentheses. 1-2-3 performs operations inside parentheses first. Within each set
of parentheses, precedence numbers apply. You can nest one set of parentheses
inside another set and create as many nesting levels as you want.

Figure 1-17 shows the order in which 1-2-3 performs the operations in a formula
that contains nested parentheses.

Using Cell and Range References in Formulas

The primary reason for using formulas in 1-2-3 is to perform calculations with
worksheet data. Use either of the following methods to include a cell or range
reference in a formula:

¢ Type the cell address, range address, or range name in the formula. If the cell
you are referencing is in another file, precede the cell’s address or range name
with a file reference (see “Linking Files” later in this chapter).

For example, to add the values in cells B1 and Cl, you can enter +B1+C1 or
@SUM(B1..C1). If Bl and C1 have the range names INSTOCK and
ONORDER, you can also enter +INSTOCK +ONORDER.

To create a formula in the current worksheet that uses the value in D25 ina
worksheet named BALANCES.WK1, you enter
+<<BALANCES.WK1>>D25.
