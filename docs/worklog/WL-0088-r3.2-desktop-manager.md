## Frictions / finds

- **Opus asset lane killed by the API content filter** while emitting long
  pixel-row hex as model output. Workaround (now bd memory
  `opus-lane-content-filter-trap-2026-08-25`): hand-author the ASCII map only;
  a one-shot transcriber generates the C rows via shell redirection.
- **The design doc is wrong about Geneva.** F1-4's Chicago-substitution
  question assumed no Geneva strike exists; `FONT_GENEVA9` +
  spec/assets/geneva9.h are fully landed. Labels are Geneva (period-correct);
  recorded in finder_desktop.h so nobody "fixes" it backward.
- **tdnl.8's DB skeleton lives at os/milton/desktop_db.{h,c}** (not the
  design's os/flair/finder_db.c) and had NO record I/O -- the codec/IO split
  (bytes in os/flair, FAT in os/milton, kmain joins) is the layering-clean
  resolution.
- **Kernel window pressure:** R3.2 added ~11KiB; tenants-only objects moved to
  `KERNEL_TENANTS_OPT=-O1` (-Os trips a gcc array-bounds false positive on the
  fixed-address boot_info read under -Werror). ~4KiB headroom left ->
  initech-uzjc files the KERNEL_SECTORS bump as its own tri-emulator-gated
  change. Do NOT let tdnl.10 absorb it silently.
- **Measured double-click delta on the booted image: 8 PIT ticks** (stable at
  both bisection bounds), vs the shipped 20-tick budget -- 60% headroom. The
  constant stays 20 (golden-resolves against a period Mouse-panel capture).
- **qmp_inject_mouse has no modifier tokens**, so shift-click extend is
  emu-unreachable and host-covered only -> initech-05rz.
- Lane worktrees + serialized main-tree writers worked cleanly as the codex
  replacement: sonnet recon (2 agents) -> opus lanes A/B in worktrees ->
  opus lanes C/D serialized on main, orchestrator grading every diff and
  re-running every oracle first-person between lanes.
