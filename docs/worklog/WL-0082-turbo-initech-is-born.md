## What changed (commit `b71961f`)

`os/tps/` is no longer empty. `tps.pas` — 934 lines of subset Pascal, the
single-file bootstrap — implements the TPS lexer (full B1–B8 keyword surface
plus `case`, canonical case-insensitive identifiers in the ratified char
pool, decimal integers, ''-escaped strings, both comment styles, located
fail-loud errors) and a token-dump driver reading the fixed `TPSIN.PAS`
through the B8 RTL. The dump protocol is specified in `LEXER-DUMP.md`.
Notable adaptation: source bytes are packed three-per-integer in a static
array (the seed stores array-of-char elements four bytes apart; naive storage
would blow the DOS BSS reserve — packed, BSS is 62,780 B inside 64 KiB).

**The oracle set:**
- `test-tps-lex-fpc` (host): a HAND-COMPUTED 73-line golden is the
  independent root (Law 2), plus four error-fixture goldens, plus the
  self-lex smoke — tps.pas deterministically lexing ITSELF (4,261 lines).
- `test-tps-lex-build` (host): the seed compiles TPS clean; both runtime
  links (bare-metal ELF + DOS `TPS.COM`, 13,676 B).
- `test-tps-lex-os` (emulator, in TEST_EMU_GATES): THE TWO-LEVEL
  DIFFERENTIAL — the seed-compiled `TPS.COM`, booted on InitechDOS, produces
  a serial token dump BYTE-IDENTICAL to the fpc-compiled binary's stdout for
  the same input. One gate catches both seed miscompiles of TPS and TPS
  logic bugs. Green on the first orchestrator run; extraction mechanics
  (anchored singular markers, CR normalization) eyeball-verified against the
  B8 DIR-listing-grep trap class.
- Rule 6: source mutants `TPS_LEX_MUT_CASEFOLD` / `TPS_LEX_MUT_STRESC`,
  generated by double-guarded sed (exactly-once anchor + no-op check), both
  RED for the right wrong value. Corpus-level mutants arrive with B9.5's
  real `test-compiler`; the on-OS gate's runtime axis is covered by the
  same-runtime `test-seed-fileio-os-mutant`.

## Watch items for B9.2+

- DOS BSS headroom: 62,780 of 65,536 B used at the LEXER stage. The parser/
  symbol tables/codegen buffers will need either a bigger reserve (memory-map
  decision) or continued packing discipline — surface this EARLY in B9.2.
- No `Halt` primitive in the subset: lexical errors print deterministically
  but return normally. Fine for the dump driver; revisit if a later slice
  needs a nonzero exit surface (the RTL's AH=4Ch AL=1 path exists for RTL
  errors).
