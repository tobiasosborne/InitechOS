## What changed and why

The class now selects ibm, ashtontate, lotus, wordperfect, borland, apple
or operations. It selects Termes 10.5/12 for IBM, operations and WordPerfect,
and Pagella 10/12 otherwise. The physical block is 142 x 186.3 mm, with
22/13.8 mm mirrored margins and a 34+4+104 mm grid fixed left on both pages;
Lotus uses its 132 mm single-column measure. Key names are body small caps.
Family-specific chapter openers, folios, headers and feet replace the old
single style. IBM gets its mini-contents, Notes verso, tab, chapter-page
folios and Index-n; Ashton-Tate gets section prefixes and X-n; the other
families follow their PG furniture. DictionaryHeads/LibraryHeads enable
reference guide heads. WordPerfect section divider leaves have blank versos.
DRAFT chapter labels propagate to contents, opener watermark and running foot.

The cover/title grid uses EB Garamond 40, band 55..61.5 mm from the top,
left bleed to x=153 mm, and the part-number/print-code block. The DOS
User's Guide selects ibm and carries the ratified 1024-3300-11 A1-3/92.
The unspecified print country is omitted. The common honest colophon is
the last interior page; padding preserves four-page signatures. Fonts are
pinned with hashes in pubs/fonts.lock. LuaTeX's cache is writable under
build/ and independent clean PDF builds agree byte for byte.

The new C oracle reads the class's emitted entry/mention indexes and the
build-derived command inventory: preprocessed command.c data table,
FLAIR_FIXTURES APPS executables and the actual int21.c controlled register.
There are 108 names, four reference entries and 104 explicit dated pilot
omissions, printed loudly every run. Inline commands are checked too.
Allowances cannot be stale or already documented; growth is checked against
HEAD and HEAD^. The initial new-file bootstrap is loudly identified, since
neither historical commit contains an allowance file.

Every Screen has a .keys / expected .txt pair and a settlement marker,
with the printed figure registry checked against the live capture route.
Transcript registers a .prg / printed .txt pair; the real InitechBase
salary specimen is replayed through SAMIR's host PAL/interpreter. Neither
expected text route is regenerated by the correctness gate. Source lints
cover ASCII, the period deny-list, years, PN/print-code formats and the
existing zero-overfull cap. The literal colophon exemption is centralized.
See harness/pubs/README.md for the precise source-scope rules.

## Frictions and acceptance

contents, opener and Notes, recto/verso body grid, command entry, screen

measure errors in Ashton-Tate/Lotus and Borland's opener parser branch.
