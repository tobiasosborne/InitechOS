# Approved Initech menu mark

`a-three-blocks.h` is an unchanged copy of candidate A from the phase-2
design handoff, `P2/marks/a-three-blocks.h`, approved by the operator in
initech-z0fxl. Its provenance and comparison are in `P2/marks.md`.
This is authored Initech art derived from the boot logo, not a historical
capture. The fixed drawing contract is a 16 by 15 cell at (15, 2), with
MSB-left rows and transparent zero bits.

The test includes this separately supplied mask as its expected pixels;
it never derives expected pixels from the product asset. The legacy
identifiers in this unchanged handoff are renamed only by test macros.
